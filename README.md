# Agentic-AI

Small Python demos built with [Streamlit](https://streamlit.io/).

## BMI Calculator (`app.py`)

A simple web app that calculates Body Mass Index (BMI) from weight (kg) and height (m) and shows a category message (underweight, normal, overweight, obese).

### Run locally

```bash
pip install streamlit
streamlit run app.py
```

Then open the local URL that Streamlit prints (usually http://localhost:8501).

### Note

This is a learning project. BMI is a general screening number, not medical advice.
